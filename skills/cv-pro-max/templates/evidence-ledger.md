# Evidence Ledger

> One place to trace important claims back to their source.

| ID | Claim | Source | Evidence Class | Confidence | Allowed Wording | Used In |
|---|---|---|---|---|---|---|
| E001 | | | FACT / VERIFIED / INFERENCE / HYPOTHESIS / UNKNOWN | High / Medium / Low | | |

## Rules

1. Every important metric gets a source.
2. Every company-specific claim gets a source.
3. Candidate facts must come from candidate evidence.
4. UNKNOWN stays UNKNOWN until resolved.
5. Never replace a missing metric with an invented number.
