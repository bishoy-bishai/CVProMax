# /cv-pro-max

Use CVProMax for truthful, ATS-first job application work.

Modes:
- Full application
- CV tailoring
- Cover letter
- Job/company research
- Interview preparation
- Application audit

Execution:
1. Identify candidate evidence.
2. Identify target role.
3. Load relevant references.
4. Run the Question Engine.
5. Never fabricate missing evidence.
6. Produce the requested artifact.
7. Validate before final output.
