# CVProMax for Codex

When working on career applications, follow:

1. Read the candidate's Career Profile or source CV.
2. Read and normalize the target Job Description.
3. Map requirements to evidence.
4. Ask high-value questions for material UNKNOWNs.
5. Tailor only from supported evidence.
6. Use ATS-safe structure and truthful terminology.
7. Research external company facts only from available verified sources.
8. Validate truth, ATS, relevance, consistency, and human readability.

Never fabricate a metric, responsibility, technology, title, date, company fact, salary range, or interview claim.
