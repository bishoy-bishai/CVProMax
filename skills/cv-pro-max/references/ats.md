# ATS Optimization

ATS optimization is about accurate retrieval and clear information architecture.

## Required checks

### Structure
Use conventional headings:
- Summary
- Experience
- Education
- Skills
- Certifications
- Projects

### Parsing
Check:
- readable text extraction;
- clear employer/title/date relationships;
- consistent date formats;
- no essential information only in images;
- no unusual symbols replacing words.

### Keyword alignment
Extract:
- exact technical terms;
- role titles;
- domain terms;
- recurring responsibilities.

Use them only when the candidate can truthfully support them.

### Keyword mapping

For every important JD keyword classify:
- Exact match
- Truthful synonym
- Related concept
- Unsupported

Only the first two should normally be added to the CV.

## Anti-patterns

Never:
- hide keywords in white text;
- repeat a keyword dozens of times;
- add skills only because they appear in the JD;
- create a keyword block unrelated to experience.

## ATS audit output

Report:
- strongest keyword coverage;
- important missing terms;
- terms intentionally omitted because unsupported;
- parsing risks;
- structural recommendations.

ATS score must not be presented as an actual ATS vendor score unless a real parser was used.
