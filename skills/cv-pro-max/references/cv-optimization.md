# CV Optimization

## Objective

Create the strongest truthful version of the candidate's CV for one target role.

## Transformation order

1. Target role
2. Relevant evidence
3. Evidence strength
4. Ordering
5. Wording
6. Keyword alignment
7. Compression
8. Validation

## Summary

The summary should establish:
- seniority;
- core technical identity;
- strongest relevant domain;
- 2–3 differentiators supported by evidence.

Avoid generic claims such as "results-driven professional" unless the wording adds real information.

## Experience bullets

Use:
Action + Context/Technology + Ownership + Result

Not every bullet needs a metric. A missing metric is not permission to invent one.

## Relevance budget

Recent and relevant roles receive more space.

For older or low-relevance roles:
- retain factual history;
- compress details;
- keep important transferable evidence.

## Skills section

Group skills by meaningful categories.

Do not list a technology solely because the JD contains it.

## Tailoring log

Record:
- bullets promoted;
- bullets compressed;
- terminology aligned;
- skills added or removed;
- gaps intentionally left visible.

## Final check

The tailored CV must remain truthful if the job description is removed.
