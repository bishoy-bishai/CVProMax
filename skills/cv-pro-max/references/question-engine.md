# Question Engine

Ask questions only when the answer can materially improve the application.

Priority:
1. Missing evidence for a top requirement
2. Missing measurable impact
3. Missing ownership or scope
4. Missing seniority context
5. Missing role-specific motivation
6. Low-value polish

Prefer concrete questions:
- What did you personally own?
- What changed because of your work?
- How large was the scope?
- Which technology did you use directly?
- What measurable result can you verify?
