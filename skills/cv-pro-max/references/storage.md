# Storage Model

Separate reusable candidate evidence from one-off applications.

## Career Profile

Contains stable or reusable information:
- experience
- achievements
- projects
- skills
- education
- certifications
- domains
- leadership
- verified metrics
- preferences

## Achievement Record

Each achievement should preserve:
- context
- problem
- ownership
- action
- technology
- result
- metric
- scope
- source
- evidence class

## Application

Contains:
- company
- role
- source URL
- JD snapshot
- date
- match analysis
- questions
- answers
- tailored CV changes
- cover letter
- research
- interview prep
- status

## Status lifecycle

Saved → Researching → Tailoring → Applied → Recruiter Screen → Interview → Offer → Rejected → Withdrawn

## Integrity

Never persist an invented detail as candidate evidence.

If a value is uncertain, store the uncertainty explicitly.
